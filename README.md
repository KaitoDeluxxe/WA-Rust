# WhatsApp Desktop Light

A lightweight, cross-platform desktop wrapper around **WhatsApp Web** built with
[Tauri 2.x](https://tauri.app/) (Rust + OS webview, no bundled Chromium).

The app loads `https://web.whatsapp.com/` in a native window, persists the
login session across restarts, and routes WhatsApp Web's web-notifications to
real OS toasts. Binary size stays small because we rely on the system webview
(WebView2 on Windows, WKWebView on macOS, WebKitGTK on Linux).

## Features

- Loads WhatsApp Web directly — no local UI, no bundled browser engine.
- **Single-instance**: a second launch focuses the existing window.
- **Persistent session**: cookies, localStorage, IndexedDB, and service-worker
  state survive restarts (per-OS app-data profile directory).
- **Native notification bridge**: replaces the webview's often-broken
  `window.Notification` with real OS toasts via
  `tauri-plugin-notification`.
- **User-Agent normalization**: WhatsApp Web sees a standard desktop Chrome UA
  regardless of which OS webview is hosting the page.
- **Windows-native dark title bar** via DWM (caption + text colors).
- **Camera/mic passthrough** for voice/video calls (OS handles prompts).

## Prerequisites per OS

- **Windows 10/11**: [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visualcpp-build-tools/),
  [Rust toolchain](https://rustup.rs/), and the **WebView2 Runtime** (preinstalled
  on Windows 11; on 10 install the Evergreen runtime from Microsoft).
- **macOS 11+**: Xcode Command Line Tools (`xcode-select --install`) and Rust.
- **Linux**: `webkit2gtk-4.1`, `libayatana-appindicator3`, `librsvg2`, plus the
  usual build essentials.

  ```bash
  # Debian / Ubuntu
  sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
  ```

## Build from source

Install the Tauri CLI once:

```bash
cargo install tauri-cli --version "^2" --locked
```

Then, from the project root:

```bash
# Dev (hot-reload-ish, no auto-reload for our static shim):
cargo tauri dev

# Release bundle for the current OS:
cargo tauri build
```

Output artifacts:

- **Windows**: `src-tauri/target/release/bundle/msi/*.msi` and `bundle/nsis/*.exe`
- **macOS**: `src-tauri/target/release/bundle/dmg/*.dmg` and `bundle/macos/*.app`
- **Linux**: `src-tauri/target/release/bundle/deb/*.deb` and `bundle/appimage/*.AppImage`

## Release workflow

`.github/workflows/release.yml` builds all three platforms on a tagged push:

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions will produce MSI/NSIS, DMG, and DEB/AppImage artifacts and
attach them to the release.

## Session data location

The webview profile (cookies, IndexedDB, etc.) is stored in the OS app-data
directory:

- **Windows**: `%APPDATA%\com.whatsapp.desktop.light\`
- **macOS**: `~/Library/Application Support/com.whatsapp.desktop.light/`
- **Linux**: `~/.local/share/com.whatsapp.desktop.light/`

To log out, quit the app and delete that directory.

## Privacy

This wrapper just loads the real WhatsApp Web page. **No message content is
intercepted, copied, or transmitted by the app itself.** The webview profile
data (cookies, localStorage, IndexedDB) is written to your local app-data
folder only — same as a regular browser. The notification bridge simply
forwards web notifications to the OS notification center.

## Regenerating icons

```bash
python scripts/generate_icons.py
```

Requires Pillow (`pip install pillow`). Produces all PNGs, a multi-resolution
`icon.ico`, and an `icon.icns` in `src-tauri/icons/`.
